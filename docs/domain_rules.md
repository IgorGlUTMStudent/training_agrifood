# Domain-rule guard

## Current validated state

- No validated agronomic rule set exists yet.
- No crop-specific thresholds are approved.
- No intervention-effect table is validated.
- No rule in this repository should be interpreted as agricultural advice.

## Rule admission process

Every proposed rule must enter a review register with these fields:

| Field | Required meaning |
| --- | --- |
| Candidate rule | Precise, testable statement; still not active |
| Source/provenance | Traceable primary/domain source and access/version information |
| Scope/crop | Crops, conditions, geography, facilities, and exclusions |
| Validation status | Proposed, under review, validated, rejected, or retired |
| Version | Version of the rule and its supporting evidence |
| Notes | Assumptions, conflicts, uncertainty, and reviewer decisions |

A candidate becomes usable only after evidence review, scope definition, data compatibility checks, implementation tests, and explicit domain approval. Changes require a new version and audit trail.

## Future research candidates, not accepted rules

Q10, vapor pressure deficit (VPD), Arrhenius relationships, crop-specific storage ranges, and FEFO may be investigated after dataset and domain reconnaissance. Their mention here is not adoption, validation, or authorization to hardcode them.
